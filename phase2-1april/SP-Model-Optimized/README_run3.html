Dental Caries Surface Classification Run 3

1. Project Overview

  • Objective: Classify caries surfaces into Occlusal, Mesial, or Distal.
  • Approach: 13 geometric features + Random Forest + Smart Fallback.
  • Dataset: 500 annotated dental panoramic X-ray cases.

3. Feature List

13 PCA-aligned geometric features: is_upper, x_mean, y_mean, x_std, y_std, x_min, x_max, y_min, x_range, y_range, x_centroid_dist, aspect_ratio, coverage.

5. Key Design Decisions

GroupShuffleSplit by case_id prevents data leakage. class_weight='balanced' corrects for class imbalance. Smart Fallback filters out 'Other' predictions.
